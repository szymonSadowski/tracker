# 🧭 Planning Techniques

## Prompt (verbatim)

Which planning techniques did the team use over the last 7 days? Break down our sessions by planning technique and named planning skill — things like pushing back on the agent, writing and saving plans, gap analysis, and scope control — so I can see how the team steers work up front. State how much of the work has analysis coverage, rank the techniques by how many sessions used them, and for the top ones pull a couple of example sessions and explain how the technique actually showed up. Keep it factual — no claims about whether a technique made sessions faster or better.
