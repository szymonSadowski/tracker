# 📊 Got done this month?

## Prompt (verbatim)

Executive summary of the last 30 days: biggest deliverables, momentum, contributors. Output shape: the headline is the month's defining achievement; then the top 5 deliverables, one line each (what, impact, owner); then 2-3 headline metrics at team level - never a per-person contributor table, owners appear on deliverable lines only; then a one-line momentum verdict. State the data window actually covered - if the data is capped or partial, say so in the muted line instead of presenting a partial window as the full month.
