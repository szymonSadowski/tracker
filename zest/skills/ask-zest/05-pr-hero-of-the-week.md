# 🦸 PR Hero of the Week

## Prompt (verbatim)

Crown this week's PR Hero - the human with the most impactful merged pull requests over the last 7 days. Judge by merged PR count, size and complexity, and review turnaround. If the top account by volume is unmapped or automation-scale, crown the top mapped human instead and mention that account only in the muted line. Output shape: the headline crowns the hero with their key stats; then a medal (🥇🥈🥉) leaderboard table of the top contributors (name, merged PRs, avg cycle time); then one standout fact per top-3 contributor - praise the podium, never dunk on anyone below it.
