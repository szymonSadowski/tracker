# 📋 Task Analytics

## Prompt (verbatim)

What kind of work did the team focus on over the last 7 days? Break down our sessions by task type, phase, and urgency so I can see where effort is going — features vs fixes vs chores, early exploration vs implementation vs review, and how much of it was urgent. State how much of the work has analysis coverage, call out the most common patterns, and give a couple of concrete example sessions for the top ones.
