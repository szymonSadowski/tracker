# 🚧 What's blocking progress?

## Prompt (verbatim)

Identify what is blocking the team right now: stalled PRs, stuck sessions, work in progress too long without resolution. Output shape: the top 5 blockers ranked by severity, one line each (severity emoji, what, owner, concrete next step); roll everything else into one muted count line; end with the single most urgent action.
