# 🏆 Best Demos

## Prompt (verbatim)

Build this week's demo reel - the team's most show-worthy shipped work from the last 7 days. Use merged PRs as the backbone, cross-reference the AI sessions that produced them, and pick the top 5. Favor user-facing features and high-impact work; skip routine chores. Exclude automation-scale accounts from the ranking and report them only in the muted line. Output shape: one line per demo - emoji, what shipped, who built it, PR link, and a few words on why it's demo-worthy.
