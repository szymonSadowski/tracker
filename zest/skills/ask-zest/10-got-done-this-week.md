# ✅ Got done this week?

## Prompt (verbatim)

Summarize what the team shipped in the last 7 days: merged PRs, closed issues, key milestones. Output shape: the headline is the single biggest win; then the top 3 wins, one line each (emoji, what, who, PR link); then up to the top 8 active people, one line each (name - their main shipped item), rolling any remaining people into a single muted count line. Count bot/automation output separately in one muted line.
