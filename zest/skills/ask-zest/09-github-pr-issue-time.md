# 🎯 Github PR Issue Time

## Prompt (verbatim)

Analyze GitHub issue lifecycle (creation to close) over the last 14 days: median time, trend vs the previous period, longest-open issues, and anything that looks stuck or forgotten. Output shape: a headline verdict; top stuck issues one line each; one takeaway. If issue data is missing or not syncing, say so in at most 5 lines - what is missing, the most likely cause, one next step - and do not pad the answer.
