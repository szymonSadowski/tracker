# 📝 Write next weekplan

## Prompt (verbatim)

Write next week's plan based on open PRs, unfinished work, recent focus areas, and current momentum. Output shape: priorities ranked P1/P2/P3, one line per item (what, owner, why now); then up to the top 8 team members, one focus line each that must not restate a P1-P3 item - reference it by PR number and add what comes after it instead, rolling the rest into a single muted line; then the single biggest risk in one line. Do not add a risk-register section.
